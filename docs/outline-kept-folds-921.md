# Kept outline folds

An outcome's disclosure is kept per reader, instance and browser device by
the existing Opened owner. Changing one outcome rereads the current stored
choices and changes that key only, so navigating in another tab cannot
overwrite a fold. Arrival opens its current outcome and folds nothing else.
Unavailable storage keeps choices on the current page.

Open all and Fold all set the default for every outcome, including outcomes
not loaded yet, and clear previous exceptions. An individual fold or open
afterwards is an exception to that default. Before either all command, new
outcomes start folded except the current outcome. New/Waiting filters remain
temporary projections and do not change kept choices.

The Keys legend and interaction guide describe these same actions. Real
OutlineRail checks cover two tabs, More outcomes after twenty, and rebuilding
after the last action folds w2; handler fixtures are not native-input proof.
