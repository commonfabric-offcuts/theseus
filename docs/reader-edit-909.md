# Double-click your text in the Reader (909)

A plain primary-button double-click on your editable message text in the
Reader runs the existing More → Edit descriptor. The Reader remains open;
Save, Cancel, Use saved and Escape return focus to its More button. The second
mousedown prevents word selection, and the accepted double-click clears the
selection before starting Edit.

Other authors, agent identities, unavailable sources/topics, reached outcomes,
Notebook sources and an active edit retain their existing behavior. Links,
buttons, images, editable fields, modified clicks and Reader whitespace keep
their own actions. No Reader header pencil is added. Feed gestures stay with
the existing feed owner.

The retained app wiring checks exercise the actual listeners and shared Edit
owner, including all four endings. The native fixture checks real double-click,
selection and focus at desktop and narrow widths in Chrome for Testing.
