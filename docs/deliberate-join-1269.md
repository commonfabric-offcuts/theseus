# Deliberate dossier joining

Reordering is personal and immediate. Joining changes the shared dossier.
Every feed join ingress (menu, phone sheet, Shift-Command-Up/Down) first
opens a menu naming the source and destination, with Cancel focused. Only
activating its named Join choice commits through the existing owner.

The choice captures the feed visit, authority, topic, source/root/target
identities, the source join revision and its current neighbor on the same
side of More. Confirmation compares those facts again. A changed or hidden
neighbor, removed source, retired visit, pending/uncertain join or changed
authority refuses; it does not silently retarget. Core still owns admission,
revision fencing, pending operation identity, retry, and Undo.

Opening or dismissing the choice records nothing and keeps personal placement,
names and covers. Escape, Tab, outside pointer and anchor-moving scroll use
the existing menu dismissal and focus restoration. Repeated activation cannot
commit twice. A deliberate join keeps the existing reveal/focus and Undo;
1268 Split back out remains available.

Own controls name menu pointer/touch-shaped activation, shortcut routing,
arrows/focus, dismissal, stale facts, source-root preservation and existing
join/Undo behavior. Mini-DOM and callback controls do not establish native
gestures, layout, focus rings or viewport/selection acceptance. Tony's original
native trigger remains unproved. No Core/schema or movement algorithm changes.
