# Send placement and temporary room (1275)

A pending send and its canonical replacement keep the same visible position
when the page's natural scroll range permits it. When the old coordinate
requires scrolling before the start or beyond the end, use the nearest natural
position. A completed send must not leave extra list padding to manufacture
that unreachable coordinate. The following generic paint starts from the
settled position, so it cannot inherit and recreate send-created room.
The pending keeper invokes its eligible restore owner even when an inner
hold has already made the measured delta zero; its default scroll-only
path still issues no zero-delta scroll.

This changes the send-specific restoration owner. Reading a long card,
writing, loading older pages and explicit card actions retain their existing
hold policies. A newer focus or selection keeps the existing pending keeper's
fences; this repair adds no focus, navigation or delayed restoration.

Temporary room belongs to the closure that installed its exact CSS value and
priority. Cleanup restores the preceding inline value only while that closure
is still the current owner and its value remains installed. An old cleanup
cannot erase a newer hold or an external style change. Stopping the page's
anchor watcher or retiring its shell releases its current room and observers.
