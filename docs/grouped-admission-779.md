# Bounded grouped compose admission (779)

This is an explicit second continuation envelope, not source equivalence. V1
is unchanged. V2 retains its original source/controller/base/merge checks and
all completed logical steps. Its sole missing logical step must be compose.
The completion workflow and matrix are frozen by a separate independent patch
review. Each actual job/archive is authenticated before any group counts.

`compose` is a digest-addressed JSON packet: version, product, original_anchor,
package, partition, inventory, inventory_review, originals, groups, collector,
review. `original_anchor` is the unchanged source run/attempt/tested_merge/base
and controller from the outer guard. `package` binds exact original and patched
harness bytes, patch bytes, producer files and workflow. `review` binds the
canonical packet body, exact patch and workflow under an auditor record distinct
from the judgment audit. It cannot authorize a changed product input.

Inventory is reconstructed by the guard-owned browser-free enumerator from Git;
its complete rows and every read input hash must equal the offered inventory
and an independently reviewed inventory. No case action is invoked. The frozen
775 collector is recomputed from authenticated actual receipts, never trusted
because an aggregate says complete. The same verifier exposes fullChecks mode
with zero retained cases for future plans.

Originals keep their exact JSONL bytes, phase checkpoint, later log and source
hash manifest from authenticated ZIPs. Only whole completed phases count. Every
partial row remains an ordered source prefix, including false rows. A checkpoint
browserClosed flag is not final cleanup. A separately authenticated retirement
receipt must identify the original archive and prove no owned work remains;
closure claims cannot replace the original false/unknown values.

Groups require exact native rows, phase, engine, case IDs, body/provenance,
original/patched source binding, final phases, own runtime engine, clean ending,
fixture endings, no terminal timeout, and producer retirement. Every raw false,
including expected mutants, needs an exact origin-qualified independently audited
disposition referencing an existing record. None becomes a pass. Complete union
and step classification are distinct; own-case proofs remain the old guard's.

No runtime producers or actual accepted landing are claimed by offline fixtures.
A real receipt missing the new job binding/retirement certificate refuses until
its producer is separately reviewed. Installation requires a whole frozen guard
checkout plus the exact pinned sibling selector patch, never helper-file copying.

## Entry points and literal packet shape

A base-move source keeps all V4 fields; its `continuation` reference may now
point at `{version:2, authorization:REF, original:RUN, completion:RUN,
compose:REF}`. The authorization's sole logical plan row is
`{name:"compose-union-779",steps:["native-compose"]}`. The original full run
must lack only compose. All other original assignments, complete reports, raw
verdicts, controller checks and own-case receipts use the existing readers.
The group matrix is checked against its actual authenticated job assignments,
source package and separately frozen workflow; it is never parsed as V1's
ordinary matrix. Each completion archive must match the outer run/attempt and
archive reference exactly.

A future judged-first train can instead opt into `full_checks:REF`, mutually
exclusive with base_move/scoped/source_carry. It names a complete original
source object with `compose:REF`, retaining original producer/controller facts.
The tested merge, current base and final tree are independently checked. The
complete source reader permits repeated compose assignments only here, binds
every group to its exact planned job, and reconstructs the literal 775 aggregate
step from the authenticated collector. Other steps and ordinary native commands
still go through their existing readers. This does not change the hosted
ci_known_reds classifier or default Verdict controller.

A packet's `package` reference resolves to:

```
product_harness: REF, patched_harness: REF, patch: REF,
producer: {each of the six 775 producer filenames: REF},
workflow: REF, workflow_head: SHA, commands: {group ID: exact argv}, review: REF
```

The patch is an exact UTF-8 unified diff with `product/` and `instrument/`
labels, never an equivalence declaration. The independently reviewed package
binds all producer file bytes, command paths, workflow bytes and patched source.
No producer is loaded from that packet. The verifier uses its own frozen copy
of 775's collector and enumeration algorithm; these remain conditional on
independent 775 review and are not an approval of 775.

Each `binding` has exactly `run attempt run_head workflow_head event job
job_name id name archive`. Run head and workflow source are distinct for a PR;
manual continuations require their actual dispatch head. Archives authenticate
API run/workflow/attempt/job, repository, digest, size and upload window. Data
is read directly from ZIP members. No profile is consulted by this verifier.

Each group archive must contain the original 775 group.json, native.json,
group-receipt.json, source-binding.json and native-compose.log, plus
`admission779.json` with exactly:

```
version run attempt workflow_head workflow_sha256 job group product
package_sha256 command origins checkout source_restored producer_retired
```

Version is 1; restoration and retirement are literal true. Native scope.origins
and binding.actual_runtime.fixture_origins must equal the certificate's two
or more distinct loopback origins; actual_runtime.source_checkout must equal
its distinct disposable checkout. Native own-engine version evidence, group
completion/case inventory, originalWholeCompleted=false, source claims, fixtures
and browser closure, raw log totals and producer exit are all checked. A timeout
artifact, cancelled/timed-out job, missing certificate, stale hash, unknown case,
wrong phase/engine, or unretired producer refuses even if another field says true.
These added certificates/observations are producer obligations, not facts
already emitted by the frozen 775 wrapper.

`originals` is one authenticated partial archive in continuation mode, and empty
in fullChecks mode. Its progress/phases/log/hashes/dispatch fields name literal
members. `retirement` is `{binding:...,member:...}` in a separately authenticated
archive; its member binds original_archive_sha256 and literal true
producer_retired/browser_closed/fixtures_closed/source_restored. The partial dispatch must also name the unchanged outer original run/attempt
and release base; its older original_source stays literal and separately
qualified. Retirement must be produced by the exact reviewed workflow in its
retire-original-compose-779 job, not an arbitrary Checks run. The original
checkpoint and cleanup uncertainty remain in the result after retirement.

`dispositions` resolves to `{false_rows:[{origin,row}],records:[REF...]}`.
Every false row stays byte-equivalent in order and with its original/group
origin. Each prior record identifies auditor/record/ground, the exact observed
origin and row, and expected-mutant or independently-placed-red category. A
mutant category also requires the authentic raw expectedFailure=true and
mutationCaught=true. The enclosing admission review freezes these prior record
bytes; a producer's category label alone grants nothing. None makes raw passed
true. Original partial false rows remain even after a replay passes.

Each review has exactly version/reviewer/record/body_sha256/kind. Reviewer is
`auditor`; inventory, source-patch and compose-admission records are distinct
from one another and from the judgment audit. These are the existing external
independent-review trust model, not cryptographic human signatures. Admission
cannot establish independence merely by an unreviewed candidate-supplied name.
An installer must obtain and authenticate the named independent records.

Group policy deadlines remain 300 seconds at most per case, a 4,400-second sum,
5,400-second producer wall, 5-second host-exit bound and 120-minute capacity,
with the original seed/launch/phase/ending reserves. They are failure bounds,
not timing measurements or proof that a case ran. No measured geometry is
introduced by this tooling change; position/size tolerances are inapplicable.

The grouped API reader authenticates at most512 jobs, in complete pages of100;
all pages must report the same total, every job must have the same immutable
run/attempt/head, and duplicates across pages refuse. Facts are cached only
within that one validation. The126-group packet fits this bound. V1's original
single-complete-page rule remains unchanged.
