# Retraction on reply lines and repeated Unsend (924)

A reply's parent excerpt carries `reply_to_removal` when that parent is
readable. A private or withheld parent reveals no removal metadata. The
shared reply-line painter strikes and dims only the parent's original words;
the author, Retracted label and act time stay outside that decoration.
Loaded replies learn a parent's terminal act and retain it across late reads.
This changes the compact Replying to line, not published quotes or writing.

The removal commands alone may reach an unsent message owned by their human
caller. Existing topic access and closed-outcome rules still apply. A second
Unsend with another operation id returns the original terminal act with
`changed: false`, without another removal or work effect. Ordinary reads and
editing still refuse an unsent source; other people and agents gain no access.
924 adds no schema of its own. In the current carry, 151 uses schema 59 after
932's question closures (57) and 625's answer receipts (58); see
[the combined carry](removal-carry-151-924-59.md).

Checks cover public and private parent projections, shared DOM decoration and
late-read repainting, repeated operation ids, another person's refusal, edit
refusal and unchanged original records. They run on isolated stores and DOMs;
no native interaction claim is made.
