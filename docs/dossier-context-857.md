# Expanded dossiers and reply context (857)

A dossier with no level chosen this visit starts open. Agent-only dossiers
remain header-only; explicit levels still win. Open retains its seven-message
window. Head clicks, menus and keys use this effective level, including a
default that has not yet been saved in the page. Returning to the tab releases
off-screen unread retention, but folds only an open level explicitly chosen
this visit. A dossier open by default stays open without saving a level.

At collapsed, a reply kept because it was unread brings its loaded parent
into view, using the cycle-cut join/reply parent from the existing gather.
Only an otherwise-hidden parent is added, in its chronological place, as a
one-line fold for this view. A root is already represented by the tab.
Starred, newest, branch-head or otherwise-kept parents retain their normal
presentation. The extra context is one level only, not an ancestor scan.
Hidden-run counts exclude these context rows; drawn/focus agrees with rows.

Unread retention is distinct from star retention. Reading the reply leaves
its context in place until the existing explicit level/reset clears it.
Context rows use the existing folded drawing; a press peeks them locally
and sends no Core fold act. Explicit Core folds are untouched. Links also
peek the row. No new read, schema, command or durable setting.

Evidence uses actual arrangement/click handlers and pure order checks with
applied/restored mutations. This does not prove native gestures or layout.
