# Written links that cannot be found (958)

A written query-form link to an unavailable topic or Notebook page says why
at the surface where it was pressed and leaves the current page, URL and
writing intact. It must not enter a half-initialized destination.
Good named links still follow the page's real owner. Unknown or duplicate
plain topic names retain 864's refusal, and ordinary generated routes keep
their existing navigation and writing guards.
