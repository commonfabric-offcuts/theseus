## Validity boundaries

Outline parent discovery must preserve current visible topic membership,
ordering, disclosure and inert/access state, including a hidden rail becoming
available. Starred dossier/page links retain their existing read/retry,
navigation, focus and current-authority owners. An unchanged refresh must not
reconstruct validity by performing unrelated synchronous geometry reads.

Rail folding must preserve the seven resting rows, measured fade/reveal zone,
current-row disclosure, pointer reveal, first touch, keyboard reach and page
action dismissal. Initial rendering, row membership/order/text, wrapping,
viewport/media/zoom changes, host/footer size, image/font completion and
open/hidden/inert/access changes invalidate any derived measurements. Reads
and writes must not create a self-sustaining observer cycle. Disposal cancels
callbacks and observers; a late callback grants no measurement or publication.

The reading hold must preserve its actual selected anchor, surviving fallback,
exact character range, arrival ownership and missing scroll-range room.
Content edits, image/font/width changes, current scroll and focus, disclosure,
authoritative refresh, retirement and access changes remain real owners. A
rectangle from an earlier layout cannot replace a required current read.
Temporary room and restoration retain their existing lifecycle. The 1247
detached-snapshot cleanup and the pending-send owner must survive this slice.

No general rectangle cache or holdRoom rewrite is selected by this contract.
The current trace determines which producer and redundant read can be removed
without extending a measurement beyond its actual validity boundary.
