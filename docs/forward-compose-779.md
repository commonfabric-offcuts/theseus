# One fresh compose obligation (779, path C)

One completed Checks run, first attempt, one tested merge/tree and one reviewed
producer package. The product source is unchanged throughout that run. Compose
uses the deterministic complete source inventory, in order, in bounded groups;
there are no retained phases or earlier-run substitutions. Ordinary steps remain
once under their existing validators. A group never claims ran_whole.

Each group records actual seed origins and instance ids, checkout Git facts,
original/instrumented harness hashes, complete raw native output, parent-observed
Worker exit, wrapper wait result and byte restoration. Timeout, unknown cleanup,
missing source restoration or unrun identities cannot supply completion. Expected
mutants remain literal false with caught status. Aggregate coverage and raw green
are separate facts. No certificate is inferred for historical output.

The protected verifier reconstructs inventory from immutable Git through a
browser-free VM, regenerates the exact instrumentation, checks all source hashes,
and authenticates every original archive against paginated API job/artifact
records and upload time, then recomputes the aggregate. Both landing and Verdict
consume the same explicit contract. Existing legacy and actual-live checks stay
in force. Controller installation requires a coherent independently reviewed
whole bundle; this source return performs no install or dispatch.
