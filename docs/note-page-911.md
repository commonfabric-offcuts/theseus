# Add a Note to a Notebook page

Message remains the default. Choosing Note shows a quiet page selector beside
the Message | Note pill. New page is first and is selected on every opening;
no last target is stored. Existing pages use the topic rail's names and newest
first order. The picker reads the remaining bounded pages only when requested,
through the rail's existing Notebook list reader, never on every commit.

New page keeps its existing creation and image recovery. A selected page changes
Start page to Add card. It appends a final top-level card using NotebookPage's
card acts and NotebookWriting's existing journal, revision fences and confirmed
save. It preserves the page title, existing cards, attachments and draft mark.
Only a confirmed append clears the unchanged composer writing and consumes its
images. The same card opens picked in Cards, beside the feed where it fits and
through the existing full-page route on a narrow screen.

A deleted, unreadable, locked or unwritable destination refuses in the composer
with the writing retained. An uncertain save retains its exact existing writer
request; retry does not append the card a second time. Changing target or writing
does not reuse another job. A late answer cannot close a newer opening or clear
newer writing. The page's existing writer is reused if it is already open.

Checks exercise real composer, card act, writer and sheet owners with memory
transport/storage or explicit UI adapters. These are not physical browser,
mobile, live-data or native lock-arbitration claims.
